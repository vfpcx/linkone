## 2. P5-A：通知中心 + 撮合运营（本期详细）

### 2.1 现状基线（代码实测 2026-09-01）

| 能力 | 现状 | 缺口 |
|---|---|---|
| **站内信（notify 域）** | `Notification`/`NotificationService`/`NotificationController` 已实现：列表（unreadOnly）/未读数角标/单条已读/跳转（refType+refId）；**30+ 业务触发点已接入**（入库/出库/退货/盘点/清库/仲裁/纠错/临期/账单/申诉/强制下架，12 §4.3 + P3b + P4）| 无批量已读、无分类分组/按类型筛选、无公告类通知、前端无独立"消息中心"页 |
| **容量公示（tenant 域）** | `capacity_publish` 快照表 + `CapacityBar.vue` + `ta/Settings.vue`（US-TA-10 三档可见性 + 精度档已实现）| 维持现状（拍板不做按 viewer 脱敏）|
| **平台公告** | 无 | 全新 |
| **撮合页运营** | 撮合资料基础（US-WA-07）已有 | 店铺页主推商品 / 置顶批发商（US-TA-09）未实现；Q-D05 上限未定 |

### 2.2 需求

#### A1 · 通知中心增强（notify 域）
- **批量已读 / 全部已读**：`POST /api/v1/notifications/read-all`（本人 scope，幂等）；列表页"全部已读"按钮。
- **分类分组**：type 常量按业务语义归组（业务 / 公告 / 系统），前端消息中心 Tab 分组；列表支持按分组筛选。
- **公告类通知**：新增 `TYPE_PLATFORM_ANNOUNCEMENT`（复用 notifications 表，零 DDL 先例见 D-P5-5），与平台公告联动。
- **前端消息中心页**：管理端 + 司机端 H5 通用消息组件（列表/分组/已读/跳转），替换当前零散角标。

#### A2 · 平台公告（US-OPS-04，Q-D08 收口）
- 平台运营后台「公告管理」：发布（标题/正文/目标角色组：全部 / 平台运营 / 仓库主 / 库管+仓库员工 / 批发商+员工）/下架/列表。
- 发布即向目标角色生成 `TYPE_PLATFORM_ANNOUNCEMENT` 站内信（通知中心常驻）；**登录首页弹窗 1 次**（Redis 按 (用户, 公告) 去重，确认/关闭后不再弹）。
- 公告对已存在的账号增量推送（存量用户登录时按发布时点补可见）；不做实时全量扫描。

#### A3 · 撮合页运营（US-TA-09，Q-D05 收口）
- 仓库主店铺设置新增「撮合运营」区块：
  - **主推商品**：从本店在售商品中选 ≤20 个 + 排序，司机端店铺页/仓库广场优先展示（带"主推"标识）。
  - **置顶批发商**：从本店入驻批发商中选 ≤5 个置顶，店铺页批发商列表置顶展示。
- storefront 聚合出参扩展（主推商品序 / 置顶批发商序），前端消费。

### 2.3 DECISION 清单（拍板结果）

| # | 决策点 | 决策 | 收口对象 |
|---|---|---|---|
| D-P5-1 | 通知中心增强范围 | ✅ 批量/全部已读 + 分类分组 + 消息中心页，全做 | — |
| D-P5-2 | 平台公告形态 | ✅ 公告=站内信新 type（通知中心常驻）+ 登录首页弹窗 1 次（Redis 去重）| Q-D08 |
| D-P5-3 | 公告目标角色粒度 | ✅ 角色组批量（全部/平台运营/仓库主/库管+仓库员工/批发商+员工），不做单用户定向 | Q-D08 |
| D-P5-4 | 撮合运营上限 | ✅ 主推商品 ≤ 20、置顶批发商 ≤ 5 | Q-D05 |
| D-P5-5 | 公告落表方式 | ✅ 复用 `notifications`（新 type 常量），**零 DDL**（先例 12 §2.1-4）| 17 §6 准入 |
| D-P5-6 | 容量告警订阅（US-WA-01b）| ❌ **暂缓**：暂不需要（2026-09-01）| US-WA-01b 验收项待再评 |

## 3. 后续子期概述（开工前单独出需求）

### P5-B · 文件与语音
- **OSS 统一文件服务**（Q-A05 选型拍板）：上传/下载/预览/鉴权 URL；存量迁移（入库照片/附件/导出 PDF 暂存）。
- **ASR 语音录单**（Q-A03 选型 + Q-L01 合规）：P0 遗留能力——批发商/司机/批发商员工语音下单（S5 兜底链路 + R18 录音作废已定义）；录音保留 30 天。
- 依赖外部服务选型（需用户拍板）+ 合规。

### P5-C · 正式多端
- **司机端正式小程序/H5**（uni-app 栈，D09）：替代当前最小 H5 验证版。
- **仓库员工全功能 H5**（US-ST-06 移交：P4 已降档为三核心页响应式，全功能并入本子期）。
- **各角色 Dashboard 真实接口**：替换当前 mock。

### P5-D · 数据/规则深度（顺延池）
- D56 商品档案完整体系（spus+两级品类+spec_types/spec_values，设计已留 `skus.spu_id`）。
- D61 批次方案 A（指定批次出库/批次级盘点/批次级计费下钻）。
- D62 计费增强（per-WA/保底/阶梯，BillingRule 留位）+ 争议账单平台仲裁闭环。
- D59 仲裁增强（调证/多轮沟通/赔偿追踪）。
- 小项池：US-WE-04 客户跟进、US-RT-05 历史询价复购、US-WK-05 移库。
